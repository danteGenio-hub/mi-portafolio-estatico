# 🚀 Portafolio Web - Francisco Paredes

Este repositorio contiene el código fuente de mi **portafolio profesional principal**, diseñado para centralizar y exhibir mis proyectos enfocados en el sector gastronómico (restaurantes, comida rápida y sushi).

## 🛠️ Estructura y Proyectos Presentados

El portafolio se divide en dos grandes enfoques técnicos:

### 1. Caso de Estudio: Restaurant Arcoíris (Evolución de Producto)
* **`restaurant-arcoiris-simple`**: Maquetación estática de una carta real en HTML/CSS[cite: 1].
* **`restaurant-arcoiris`**: Implementación de lógica en JavaScript con un panel de administración local protegido por contraseña fija en el código[cite: 1].
* **`restaurant-arcoiris-supabase`**: Versión escalable full-stack que incorpora bases de datos en la nube y autenticación de usuarios con recuperación de contraseña mediante Supabase[cite: 1].

### 2. Ecosistema de Nichos Gastronómicos
* **`foodtruck-simple`**: Landing page optimizada para comida rápida callejera[cite: 1].
* **`suhi-simple`**: Interfaz temática minimalista para restaurantes de sushi[cite: 1].
* **`restaurante-chileno`**: Solución web adaptada a la gastronomía típica nacional[cite: 1].

## 💻 Tecnologías Utilizadas
* **Frontend:** HTML5, CSS3, JavaScript (ES6+).
* **Backend as a Service (BaaS):** Supabase (Autenticación y Base de Datos Relacional).
* **Control de Versiones:** Git & GitHub.
